# NFL Third-Down Conversion Prediction

## Project Overview
This project uses machine learning to predict whether an NFL offensive play on third down will result in a first down. It was completed as part of DAT 402 at Arizona State University.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib
- Jupyter Notebook

## Methodology
- Cleaned and prepared NFL play-by-play data.
- Performed exploratory data analysis and visualizations.
- Developed Logistic Regression and Random Forest models.
- Applied GridSearchCV to optimize model parameters.
- Evaluated performance using confusion matrices and ROC-AUC scores.

## Results
The models achieved the following cross-validation ROC-AUC scores:

- **Logistic Regression:** 0.698
- **Random Forest:** 0.642

Logistic Regression demonstrated stronger predictive performance based on cross-validation ROC-AUC.

## Key Takeaways
This project strengthened my skills in data preprocessing, predictive modeling, machine learning, and model evaluation while applying these techniques to real-world football data.
